# 板图与文件模型

[文档导航](../README.md) · [操作指南](../usage.md) · [完整资料索引](../reference-index.md)

## 先看结论

当前可以严格读取已覆盖的 PCB FILE 4，显示基本图元、元件和图层，保留输入字节与来源。读取成功证明满足本项目的解析规则；精确字形、全部历史变体和原软件写出兼容仍需独立证据。

## 第一层分析：板图由什么构成

| 对象 | 文件表达 | 分析重点 |
| --- | --- | --- |
| 自由图元 | FT / FP / FV / FA / FF / FS | 走线、焊盘、过孔、圆弧、填充、文字 |
| 元件实例 | COMP、内部 C 前缀图元、ENDCOMP | 归属、标号、封装及绝对板坐标；不能重复套用元件变换 |
| 内嵌网络 | NETDEF | 声明和元数据保留，转入[网络主题](connectivity.md)解释 |
| 文本布局 | 行终止、结束标记、DOS EOF | 解析边界与原字节保存，关系到后续安全修改 |

<a id="explore-ex-008"></a>

几何单位为整数 mil，1 mil = 0.0254 mm；模型 Y 向上，绘制时变换。图像像素和毫米显示小数都不改变文件单位。FT 允许已观测的六／七字段，第七字段保留原值，电气意义未确认。

[探索 EX-008](../exploration-backlog.md#ex-008)。

## 第二层分析：怎样进入程序

读取器冻结输入 → 解析几何与来源 → 生成不可变文档 → 几何层计算轮廓 → 渲染器绘制 → 画布处理视口与交互。原始布局另提供严格顶层区间和插入候选，避免在文字正文里搜索标签猜结构。

| 代码入口 | 职责 |
| --- | --- |
| [BoardDocument.h](../../src/domain/BoardDocument.h) | 图元、元件、来源、原字节快照 |
| [LegacyPcbReader.h](../../src/io/LegacyPcbReader.h) | 严格读取和解析 |
| [LegacyPcbLayout.h](../../src/io/LegacyPcbLayout.h) | 字节区间、换行及结束标记布局 |
| [BoardGeometry.h](../../src/geometry/BoardGeometry.h) | 共享轮廓、边界与命中 |
| [BoardRenderer.h](../../src/ui/BoardRenderer.h) | 绘图，不负责文件语法 |

未知记录、错误字段或结构损坏导致整体拒绝；不会跳过后返回“完整板图”。文件上限 64 MiB、结构记录上限 200000，是本项目保护策略。NETDEF、EOF 等后续扩展以新专题为准，早期只读报告的旧限制保留为历史。

## 第三层分析：已经验证到哪里

<a id="explore-ex-011"></a>

真实 PLACED.PCB、660A.PCB 已有解析及预览证据；合成测试覆盖结构错误、绝对坐标、图层、异步迟到结果和来源。文字采用近似字体，部分焊盘轮廓为近似，旧代码页未确认。不能用画面相似替代字段及语义核验。

[探索 EX-011](../exploration-backlog.md#ex-011)。

只读工具 pt-pcb-check 输出输入摘要、记录计数、自由 FT 与布局；成功退出仍明确标记原软件兼容未验证。其字段观察可以帮助核对样例，不自动选择新增默认编码。

## 下一步怎样推进

先取得来源明确的原软件单图元及保存重开样例，再逐项比较字段、布局与显示；将新事实转成严格读取或写出规则。编辑与原字节保护继续阅读[编辑主题](editing.md)，字形继续阅读[原软件研究](legacy.md)。
