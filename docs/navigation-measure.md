# 元件检索、定位与两点只读测量

阶段：第四阶段，版本 0.4.0。开发分支：`feat/component-navigation-measure`。

> 第十阶段 0.10.0 已增加可选的 [测量端点捕捉](measurement-snap.md)。本文保留第四阶段默认自由取点的范围和历史验收；第五阶段的独立 LIB 只读浏览见 [LIB 分析与浏览](library-analysis.md)。

## 元件检索与定位

- 顶部“跳转 → 检索并定位元件”、画布旧式按键 **J → C**、**Ctrl+F** 打开同一个元件检索面板。
- “信息 → 元件列表”及左侧页签也可访问列表。
- 按标号、封装或注释作不区分大小写的**字面子串匹配**，不是通配符或正则表达式；`[` 等字符不会被当成模式。
- 列表支持按列进行文本排序；排序和筛选后的行会映射回原文档索引，不把显示行号误当成元件编号。
- 输入框 Enter、列表激活（Enter/系统激活方式）或“定位当前元件”按钮共用定位逻辑；没有匹配项时不执行上一次的定位。
- 定位会将元件范围居中，并在现有缩放上限内尽量适配，显示虚线定位框及只读元件属性。**不移动、旋转或修改任何元件。**
- 定位范围包括元件所属图元和可见标签，可能大于实际封装；没有图元的元件按记录的原点定位，不伪造封装尺寸。
- 隐藏图层不会被自动开启，因此定位到完全隐藏的元件时可能只看到定位框。
- “跳转 → 跳转到原点”或画布内 **Ctrl+Home** 将板坐标 (0,0) 居中，不是恢复历史 DFT 中的浮动原点。

列表使用 `QAbstractTableModel + QSortFilterProxyModel + QTableView` 按需提供数据，不为每个元件创建一组界面控件；当前排序是普通文本顺序，不承诺自然数标号排序。载入/关闭文件会重置模型、过滤条件和定位状态。

## 两点只读测量

入口：顶部“信息 → 两点只读测量”、画布内 **Ctrl+M**。菜单的勾选状态与当前工具模式一致。

1. 进入模式后，依次在画布单击第一点和第二点。
2. 第一点显示临时标记；第二点完成后显示测量线、ΔX、ΔY、直线距离和方向角。
3. 可以继续取下一组两点；开始新一组时清除上一组结果。
4. 画布内 **Esc** 或取消测量菜单勾选会退出取点；未完成的第一点取消，已完成结果保留。
5. “信息 → 清除测量”移除结果和未完成取点，不会退出当前测量模式。
6. “信息 → 测量结果面板”恢复结果页签，不自动进入取点模式。

测量数值按 mil 计算，毫米换算为 `mil × 0.0254`。方向角是板坐标 Y 向上、相对 +X 的有符号角度（约 -180°..180°）；两点重合时距离与角度均为零。

**取点不吸附网格、焊盘中心或图元端点。** 数值受屏幕位置、缩放和鼠标精度影响，显示的小数位不代表已达到相应制造精度。结果不是走线电气长度、净距、DRC 或生产尺寸验收；不产生可保存的尺寸图元。

缩放、平移只改变测量线的显示，已记录的板坐标不变。定位元件会退出取点模式；已完成的本文件测量结果可保留。更换或关闭文件会清除所有测量状态，不能把旧文件的取点带入新文件。

Ctrl+M、Ctrl+Home 和取点 Esc 限于画布焦点，避免抢占检索输入和文本框的常规操作。弹出菜单内 Esc 只关闭菜单，不退出正在使用的测量模式。

## 实现边界

- `application/ComponentTableModel.*`：只读元件表模型，依赖 Qt Core。
- `ui/ComponentBrowser.*`：筛选、显示与激活统一入口；索引从代理模型映射到源模型。
- `geometry/BoardGeometry.*`：按来源索引收集元件包围范围和只读属性。
- `domain/Measurement.h`：临时两点坐标与数学换算，不依赖 Widgets。
- `BoardCanvas`：定位视口、定位标记、取点状态和覆盖线。
- `MainWindow`：命令可用状态、页签、只读结果输出；不写原文件。

当前定位范围的收集仍会遍历图元；大型板图性能与更复杂的空间索引未验收。圆角/八角轮廓、文字字体、历史格式变体等限制仍见前两阶段文档。

## 验证记录

新增 `pt-navigation-tests`，覆盖：

- 表模型空状态、角色与字段；跨列匹配、大小写、Unicode 模型数据、字面特殊字符、零匹配和排序后源索引。
- 元件绝对坐标范围、空元件原点回退、隐藏图层不被打开、错误索引拒绝。
- 300/400/500 mil 勾股测量、零长度、反向角度、两次点击、缩放平移、继续取点、取消、清除及关闭文件。
- 真实 GUI 的 Ctrl+F、J→C、Enter 定位、Ctrl+M、画布 Esc、菜单 Esc、Ctrl+Home 与文本焦点保护。
- 输入文件字节不变、保存始终禁用。

真实应用验证：载入 `PLACED.PCB`，列表显示 36 个元件；输入 `R7` 后显示 1/36，Enter 定位到 R7，属性为 AXIAL0.4 / 4k7，原点 (800,2875) mil。通过信息菜单及字母 M 进入测量，在两个焊盘中心附近自由点击，实际得到约 **399.55 mil（10.1486 mm）**，与原文件两个焊盘中心的 **400 mil** 间距接近，但并非精确吸附后的 400 mil。这正是近似取点与模型几何测量必须区分的原因。

操作使用仅面向本次进程窗口的鼠标/字符消息，并查看截图；未抢占系统前台或注入全局键盘鼠标。诊断截图和辅助脚本不提交。

Debug 与 Release 四组报告均为：菜单 18 项、PCB 29 项、选择 18 项、导航/测量 9 项，**各配置合计 74 项通过、0 失败、0 跳过**（包含测试组初始化及清理）。原始安装目录 99 个文件的 SHA-256 全部未变。最终 Release 部署包也在移除 Qt SDK PATH 后实际启动，完成输入 R7、筛选和 Enter 定位；这仍不是 Windows 10 干净机器验收。

## 未完成内容

仍不支持编辑、保存、封装库载入、网表连通性、DRC、自动布线或生产输出。尚未实现精确端点吸附、网格捕捉、多段测量及尺寸标注。旧格式与 LIB/NET 逆向仍需继续，不把本阶段导航/测量工具当成已经恢复这些功能。
