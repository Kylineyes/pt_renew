## 执行范围和比较方法

沿用 [受控机器码验证](legacy-text-machine-verification.md) 的 MZ 装载、重定位及内存限制。原包装 `2964:53a3`、解释器 `2964:39a2`、栈检查 `3c97:0244`、短字符串复制辅助 `3c97:0644` 均执行原机器码并使用原生远返回。绘线入口 `2964:20ef` 和简化绘制入口 `2964:22d3` 只截获参数、模拟返回，不执行绘图。

实验设置对象坐标 `(2000,2000)`、笔宽 7、颜色参数 1、字形表远指针、视图缩放、`DS:d4ed` 状态及边界初值。新增的写入许可仅限四个边界 word；对象和字体数据仍不允许写入。每次调用保持 250,000 条指令钩子预算和原函数范围检查，意外中断、越界访问、未正常返回或栈不平衡均失败。

独立参考遍历字形记录中的全部移动指令，按高度整数除以 12、旋转及镜像计算移动终点；与原解释器 `2964:3bcf` 处逐次位置比较。边界模式再逐项比较四个全局边界值，并检查绘线调用为零、对象与模式字节未被改写。正常绘制对照继续核对中心线及笔宽参数；简化分派核对五个参数。

| 用例 | 数量 | 结果 |
| --- | ---: | --- |
| 状态 0，正常解释器绘制 | 256 | 中心线、笔宽及参数一致；边界初值不变 |
| 状态 0，低缩放简化分派 | 256 | 只进入简化路径，参数一致；边界初值不变 |
| 状态 1，同一组 F 对象 | 512 | 全部进入解释器，逐移动端点及累计边界一致，无绘线调用 |
| 状态 1，空串、空格、相邻字符与边界初值对照 | 432 | 逐移动端点和累计边界一致，无绘线调用 |

F 对象矩阵包含高度 239/240/251/252、视图缩放值 1/59/60/61/62/63/64/100，以及内部方向 0–3、16–19、32–35、48–51。补充矩阵包含空串、空格、A、F、AA、A A、前后空格、32 字节 F 和 80 字节 A，交叉 16 种方向和三组边界初值。长字符串由实验直接放入对象内存，不能据此证明对象创建或保存能保留相应长度。

## 边界的具体含义

原包装在“高度除以视图缩放值小于 4 且 `DS:d4ed == 0`”时选择简化路径。模式为 1 时，该条件不成立，解释器继续处理完整字符指令；解释器内的同一状态同时抑制绘线并启用边界累计。

原边界全局依次为 `DS:d4ac` 最大 X、`DS:d4ae` 最大 Y、`DS:d4b0` 最小 X、`DS:d4b2` 最小 Y。函数以有符号比较扩展调用者提供的初值，不负责清零或初始化。累计发生在每条移动指令之后，**包括抬笔移动，但不会额外加入最初原点**。

例如实验将最大值初设为 -32768、最小值初设为 32767，文字原点 `(2000,2000)`、高度 240、方向 0、视图缩放值 100：

| 内容 | 移动次数 | 结果：最小点 → 最大点 |
| --- | ---: | --- |
| 空串 | 0 | 四个初值保持不变，不构成有效包围盒 |
| 单个空格 | 1 | `(2240,2000) → (2240,2000)`；没有绘制笔画，原点不在累计结果中 |
| F | 8 | `(2000,2000) → (2240,2240)` |
| A A | 15 | `(2000,2000) → (2720,2240)` |

这些值是受控对象和明确全局初值下的原函数结果。真实调用者的初值、实际导入状态、对象方向及原程序后续如何使用边界仍需联合运行验证。
