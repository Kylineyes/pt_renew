# 只读选择、命中测试与属性查看

阶段：第三阶段，版本 0.3.0。开发分支：`feat/pcb-selection-inspector`。

> 第四阶段已加入元件筛选/定位及两点近似测量，见 [元件检索与测量](navigation-measure.md)。下文保留第三阶段验收记录。

## 用户操作

- 在板图工作区单击图元，白色虚线标记当前选择，右侧“图元属性（只读）”显示属性。
- 同一屏幕位置再次单击，循环切换本次命中的重叠图元；也可以在画布焦点下按 **Ctrl+Tab**，或使用“编辑 → 切换重叠图元”。
- 画布内 **Esc**、“编辑 → 清除只读选择”或单击空白处清除选择。
- **Ctrl+I** 或“信息 → 图元属性面板”恢复被关闭的属性面板。
- 隐藏当前对象所属图层会清除选择；载入、关闭文件也会清除选择。改变图层集合后清空旧的重叠候选列表，避免选择隐藏对象。
- 缩放和平移只改变视口，不改写图元位置或尺寸。

Esc 与 Ctrl+Tab 的命令快捷键仅在工作区获得焦点时生效。菜单打开时 Esc 关闭菜单，不应清除原选择；文本框获得焦点时，普通文字和 Esc 不被选择器抢占。鼠标、菜单和键盘入口复用 `QAction` 命令，不各自维护不同状态。

## 结构

- `domain/PrimitiveId.h`：图元种类与文档内序号，以及源文件行号和所属元件索引。
- `geometry/BoardGeometry.*`：共享焊盘轮廓、圆弧中心线、预览字体、图元轮廓、包围盒、命中测试和只读属性格式化；依赖 Qt Core/Gui，不依赖 Widgets。
- `BoardHitTester` 缓存每个图元的包围盒作为粗筛；候选再做真实轮廓命中，不直接把圆弧外框中的空白当成铜线。
- `BoardCanvas` 管理本窗口的选择与重叠候选、坐标换算和高亮。
- `MainWindow` 显示只读属性、维护命令可用状态。解析层记录来源信息，不引用界面对象。

图元 ID 只在同一份不可变文档中有效，不是可跨文件保存的永久标识。没有为此引入可变文档、撤销栈或文件写入接口。

## 命中规则

- 点击容差是 **6 个 Qt 逻辑像素**，按当前缩放换算成 mil，不使用固定 mil 容差导致缩放后越来越难选。
- 焊盘、圆弧的显示与命中共用轮廓函数；显示顺序与选择优先顺序共用图层顺序。
- 对象重叠时，优先返回当前显示方案中后绘制、位于上方的对象；同层内按后绘制对象优先。可以切换候选，不把任意一个候选当成唯一正确答案。
- 走线按带圆头的线宽命中，圆弧按已设置象限的实际弧段命中。圆弧中心空白不会因为位于包围盒内就被选中。
- **钻孔内单击归属焊盘/过孔对象**。这里选择的是逻辑对象，而不是只挑选有颜色的屏幕像素；被钻孔遮住的下层对象仍可能作为重叠候选。
- 文字按预览字体的变换后包围框命中，而不是原 DOS 字形的精确笔画；文字框内的留白也属于候选。
- 隐藏图层不参与命中。八角/圆角焊盘仍沿用上一阶段的近似轮廓，不将选择精度宣传为生产几何校验。

当前采用线性遍历缓存包围盒加候选精测，并非已实现 R 树或对大型板图作过性能基准。以后应根据实际大型板图测量决定是否增加空间索引，不能仅因小样例操作正常就承诺所有规模下的帧率或延迟。

## 属性内容

- 通用：图元种类、图层、当前候选序号、源文件行号、所属元件的标号/封装/注释/原点。
- 走线：起终点、线宽、几何长度；有第七扩展字段时显示原值，并提示含义未确认。
- 焊盘：中心、名称、宽高、孔径、形状编号、原始平面标志。
- 过孔：中心、外径、孔径。
- 圆弧：中心、半径、线宽、象限掩码。
- 填充：矩形的最小/最大坐标、宽高。
- 文字：内容、基准点、字高、方向、镜像、原始笔画宽和预览近似说明。

尺寸同时展示 mil 与 mm（1 mil = 0.0254 mm）。毫米小数是显示换算，不替换原文件整数 mil 数据。没有将原始平面标志或第七字段推断为已确认的网络、电源属性，也没有进行连通性或 DRC 检查。

元件内部几何仍为绝对板坐标；来源索引只是关联元件信息，不再次叠加元件原点。可见元件标签分别记录其位置字段所在行。

## 验证

测试新增独立 `pt-selection-tests`，覆盖：

- 走线圆头和斜线附近空白、不同焊盘形状、钻孔中心逻辑选择。
- 四个圆弧象限与中心空白、过孔/填充/旋转镜像文字、无效 ID 和非法命中输入。
- 隐藏图层过滤及重叠绘制优先级。
- 源文件行号、元件归属、单位换算和扩展字段提示。
- 实际 GUI 鼠标选择、重复单击循环、Ctrl+Tab、菜单命令、Esc、文本框和弹出菜单的焦点保护。
- 缩放/平移坐标换算、不同缩放下的屏幕容差、隐藏图层/更换文件时的失效选择清理。
- 选择不改写输入文件，也不会启用保存。

真实应用已载入 `PLACED.PCB` 并通过定向窗口鼠标消息操作，不切换系统前台、不注入全局键盘鼠标。检查了从 R7 附近的文字、丝印线切换到焊盘的截图：焊盘名称 1，中心 (800,2875) mil，尺寸 62×70 mil，孔径 30 mil，源文件第 9 行，所属 R7 / AXIAL0.4，与输入内容一致。

诊断截图、输入辅助脚本、构建与部署产物均保留在被 Git 忽略的目录，不提交原软件、用户板图或截图。

最终 Debug 和 Release 均通过三组回归：菜单 18 项、PCB 29 项、选择 18 项，**各配置合计 65 项通过、0 失败、0 跳过**（包含各组初始化和清理）。部署后的 Release 程序也在移除 Qt SDK PATH 的环境下成功载入板图并切换到 R7 焊盘。原目录 99 个文件的 SHA-256 全部保持不变；未做 Windows 10 干净机器或大型板图性能验收。
