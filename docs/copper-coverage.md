# 铜层覆盖诊断与文字研究

阶段：第九阶段，版本 0.9.0。开发分支：`feat/copper-coverage-diagnostics`。

## 字体研究结果

原安装目录内未发现独立笔画字体文件。只读检查 `PCBTODXF.DOC`（PCBTODXF 2.01 用户文档）得到的事实是：文字输出为缩放、旋转后的 AutoCAD 文字，使用 AutoCAD 默认字体，每行厚度为一个输出像素。DXF 导出明确替换字体，因此**不能用 DXF 字形代表 AUTOTRAX 编辑画布或 DRC 所用的字形**。

对安装目录原样 `PT.EXE` 的 SHA-256 为 `abc56e2e8467e608c68a0ddf0b0705e8270c5c60f83f193fa991f10293ece968`。Ghidra 12.1.4 headless 按 `x86:LE:16:Real Mode` 导入主 EXE，识别到 910 个函数。针对 ASCII 原始内存字符串中的 font/text/character/stroke 扫描，没有找到候选字符串或到它们的已识别引用。这个有限搜索**不能证明字形实现不存在**：`TRAXEDIT.OVR` 尚未导入；DOS 图形运行时可能内嵌于其他表或通过 16 位段/索引间接访问；绘制代码也可能没有相关明文字符串。

因此本阶段不猜造笔画表，不将系统字体或 DXF 的 AutoCAD 字体当作原字形。板图文字几何与 DRC 覆盖仍然保持未知。后续如需精确恢复字形，需分别分析 `TRAXEDIT.OVR`、图形驱动 `GRAPH.DRV`，并在隔离运行副本中对单字符/单图元进行原程序对照。REA 当前不能从本 Windows DOS MZ 路径直接完成这项分析；这并不阻止用现有 Ghidra 和安全本地结构证据推进兼容诊断。

> 后续静态研究已定位默认笔画表和字符解释路径，见 [原文字形静态证据](legacy-text.md)。尚未完成原程序单字符行为对照，未将该结果接入渲染或铜层模型；本页第九阶段结论及铜层未知状态继续有效。

## 未覆盖图元诊断

受限分析结果现在会记录每个已发现覆盖缺口：图元类别、从零计索引（界面显示一基序号）、图层、源 PCB 行、元件归属以及简短原因。铜层文字还显示最多 80 个字符的值。重复问题可因需要修复的图元而分别列出，保留原始遍历顺序，避免难以把报告项与文件对象对应。

- GUI 在分析报告中显示明细。双击条目或按 Enter 会选择图元、居中并打开属性面板，不移动图元、不改写源文件，也不自动开启隐藏图层。
- 同一工作区中已有的网络、测量或选择状态按其原有载入行为清理；报告在板图、网络来源或清空状态变化时失效，不接受旧后台结果。
- UI 每次最多保留 200 条图元诊断；超过时显示完整问题总数与省略数量。
- CLI JSON 增加 `coverage_issue_count`、`coverage_issues_omitted` 和 `coverage_issues`。`source_line` 为一基物理行，`primitive_number_1_based` 为图元序号；没有具体图元归属的比较预算等分析级项目使用 `kind: "analysis"`、图元序号 0 和源行 0。
- 上限触发时，尚未遍历的图元无法逐项列出；构建时间或对象数量问题附带当时图元的来源，比较预算等没有具体归属的问题使用分析级诊断。省略条目或受中断遍历影响的明细不代表全板问题计数。完整覆盖标志和退出码语义不变。

明细以现有有界 PCB 文本中的字符串和记录内容构造，不重新读取路径、不调用 OS 命令、不展开符号链接，也不将内容解释为文件名或代码。每个原因和对象字符串受 PCB 读取器的 64 KiB 单行限制约束；界面总记录数有上限，长文字在摘要中截断。

## 验证

专项测试覆盖各图元类别、层号、源行、元件索引、文字名称、资源级无图元诊断、200 项限额，以及铜文字分析后按 Enter 定位到文字图元并显示其属性。测试确认用户手动隐藏的层保持隐藏，清除或更换网络/板图后诊断列表失效。

最终 Debug、Release 均构建成功，七组测试各 **232 项通过、0 失败、0 跳过**（包含初始化与清理）。发布目录已更新至 0.9.0，EXE 摘要与 Release 构建一致；移除 Qt SDK PATH 后实际启动隔离样例并触发分析。

`PLACED.PCB + DEMO.NET` 报告 430 个模型对象、5211 次比较、88 个网络无法确定、21 组跨网接触候选，退出码仍为 3。新增诊断准确列出 5 处铜文字，源行分别为 1992、1995、1998、2001、2004，没有省略项。实际发布窗口中选中 `AUTOTRAX` 条目并按 Enter，视图居中到该文字，属性面板显示文字内容、图层 1 和源行 1998，已查看截图。移除网表后报告与覆盖诊断列表清空，分析按钮禁用。

原目录 99 个文件的 SHA-256 与既有基线全部一致；122 项 Git 忽略/保留路径检查通过。所有临时材料留在被 Git 忽略的 `.local-analysis/verification-09/` 下。

此功能是**只读诊断工具**。铜层文字、平面层及其他未建模对象继续阻止全板网络报告“支持模型内已连接/仍分离”；没有实现完整 DRC、生产放行或文件写回。
