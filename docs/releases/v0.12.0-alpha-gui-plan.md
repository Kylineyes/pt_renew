# v0.12.0-alpha 真实窗口验收清单

用户已明确授权“你进行真实窗口的验收，务必全部覆盖”。本轮覆盖新版声明的用户功能及相关拒绝、取消和保存保护；不把有限合成场景称为所有格式、所有操作系统或完整原软件兼容验证。

## 固定候选与操作归属

- 源码：release/v0.12.0-alpha，提交`0ad5b3e842448bd9c8c0192f80380251e3282ac5`。
- Release产品：`pt-renew.exe` SHA-256 `96d7275c8c599e4013da0d06a432c0d58b3d4ed3b314e5aeb8ab99073d982f0a`；24/24组offscreen CTest通过，仅作前置。
- 唯一部署：协调树`.local-analysis/release-v0.12.0-alpha/artifacts/pt-renew-v0.12.0-alpha-windows-x64/`，119文件；ZIP SHA-256 `897b64e95597632f219633fcd39318fad97fcae9697fcc5ccc20dd714bfc637f`。部署与ZIP须逐项核对，使用期间保持文件集合及摘要不变。
- 仅一个Pi／deng／gpt-6.1-sol／high验收worker控制本项目窗口；协调只读审证，不同时发送桌面输入。沿现有独立工作树，不启动其它现场worker。
- 输入由既有合成生成器及已有测试格式生成，另放worker忽略任务目录；需要扩展LIB多图元、重叠、NETDEF或铜覆盖样例时只生成合成资料，并先用已有检查命令核可读性。原软件、安装盘、用户板库及旧现场不参与。
- 清除QT插件／开发路径和offscreen等变量；产品PATH优先只有部署与Windows系统目录，不借SDK插件。所有运行由创建时原Popen／句柄持有者观察和等待；PID与创建FILETIME原整数及映像摘要同时保留。

## 收尾与结论规则

失败记录原样保留；产品缺陷先给协调可复现步骤和最小证据，不在现场临时修改产品或用内部接口替代用户动作。需要修复时协调改独立分支，重建新候选后由同一操作者复验受影响项及必要回归。

原生文件框／未保存提示、显示平台与真实截图不能用offscreen模拟代替。G46若无法建立真实时序证据必须记受阻，不擅自插入调试门闩或声明并发已测。干净Windows、原软件往返与所有格式边界继续明确未验证，不属于这48项本机候选窗口场景。

按“通过／失败／受阻／未执行”逐项结算，只有48项都有实际通过证据才能称本清单全覆盖通过；任一未过保持PR草稿和发布阻塞。每20分钟给有证阶段状态，预算由本次用户授权覆盖完整验收，不沿用旧10–15分钟冒称全覆盖；每组保留至少5分钟正常退出与审计时间。最终报告由协调审图／回执后统一更新PR与发布说明，不能提前打tag。
