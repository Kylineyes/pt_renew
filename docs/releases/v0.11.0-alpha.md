# PT Renew v0.11.0-alpha

面向 Windows x64 的早期测试版，定位为旧版 AUTOTRAX PCB 资料只读查看器。此版本沿用已实现的只读产品功能，并整理发布版本、部署文件与使用说明。独立分支中的基础编辑候选没有包含在本次发行中。

## 已有功能

- 打开已支持的 `PCB FILE 4` 板图，显示走线、焊盘、过孔、圆弧、填充、文字与元件标签。
- 缩放、平移、图层显隐、图元选择与属性查看、元件检索定位。
- 两点测量及可选几何端点捕捉，显示取点来源。
- LIB 封装库只读浏览、名称筛选及图元预览。
- 外部 NET 载入、网络与焊盘引脚映射、高亮及冲突诊断。
- 受限铜层几何接触分析及未覆盖对象定位；不是完整 DRC。
- 顶部菜单、现代快捷键及画布焦点内的旧式字母菜单操作。

## 下载与启动

1. 下载 `pt-renew-v0.11.0-alpha-windows-x64.zip` 并完整解压。
2. 运行解压目录内的 `pt-renew.exe`，请保留配套 DLL、插件和许可目录。
3. 通过 `Ctrl+O` 打开自己的 PCB 文件，`Ctrl+L` 打开封装库浏览，`Ctrl+Shift+N` 载入外部 NET。
4. 命令行示例：`pt-renew.exe "自己的板图.PCB" --netlist "自己的网表.NET"`。
5. 使用发行附件 `SHA256SUMS.txt` 核对下载文件。程序无需安装 Python、Qt SDK 或开发工具。

压缩包内附有项目合成的 `examples/preview.pcb`，可用于首次启动。示例用于演示图形与只读操作，不是可生产的板图；不包含原软件、原安装盘、用户板图、库或字体。

## 已知边界

- 不支持编辑、保存、另存为、新增图元、元件放置／移动、交互布线或生产输出。
- 不提供完整 DRC、断路或短路确认。铜层几何覆盖不足时显示“无法确定”，不能据此判定板图可生产。
- 仅支持已覆盖的历史格式；未知或损坏记录会明确拒绝。非 ASCII 代码页兼容性尚未确认，部分文字和轮廓为近似显示。
- 本版按 Windows x64 发布；本机 Windows 11 验证结果不能代替干净 Windows 10／11 环境的完整兼容性验收。
- 本次发布不代表独立编辑候选、异步竞争实验或原字形运行时验收通过。
