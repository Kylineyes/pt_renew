# v0.11.0-alpha 构建与打包

本次发布以当前只读产品为范围。用户明确授权代理合并并操作gh发布；工作分支先进入dev，再通过GitHub PR合入main，tag绑定最终main提交。基础编辑候选与异步实验保持独立。

## 重建

在Windows x64、Qt 6.12.0 MSVC套件及已安装MSVC的环境中，打开PowerShell：

```powershell
& ./scripts/Enter-QtEnv.ps1
cmake -S . -B build/alpha -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build/alpha --parallel 6
ctest --test-dir build/alpha --output-on-failure
```

CMake的数值版本为0.11.0，完整版本`0.11.0-alpha`通过生成头文件供命令行与关于窗口共用。发布包不依赖Python；下面的标准库打包工具仅供维护者使用。

## 第三方源码与打包

从Qt官方地址下载两个对应源码归档和各自的`.sha256`文件，将归档放入被Git忽略的本地目录：

- `https://download.qt.io/official_releases/qt/6.12/6.12.0/submodules/qtbase-everywhere-src-6.12.0.tar.xz`
- `https://download.qt.io/official_releases/qt/6.12/6.12.0/submodules/qtsvg-everywhere-src-6.12.0.tar.xz`

脚本再次核对已固定的官方SHA-256；不接受不匹配来源。之后在上述开发环境运行：

```powershell
python -B -X utf8 scripts/package-release.py `
  --build build/alpha `
  --output .local-analysis/alpha-artifacts `
  --qt $env:QTDIR `
  --qt-sources .local-analysis/qt-sources
```

输出目录必须尚不存在。脚本只复制新构建，不覆盖`dist/`或历史候选；`windeployqt`保留官方Qt DLL字节，包内`qt.conf`指定相对插件路径。运行库安装器由官方开发套件提供，目标机器缺少运行库时须自行安装。

输出内容为Windows x64 ZIP、qtbase/qtsvg完整对应源码、SHA256SUMS.txt，以及本地构建记录。ZIP内包含项目MIT许可、Qt和所含第三方许可、SPDX清单、Qt构建配置、对应源码说明、合成PCB及逐文件清单。下载归档、构建、包和截图只留忽略目录或GitHub发行附件，不提交Git。
