# PT Renew v0.12.0-alpha：轻量编辑测试版（发布候选）

本版本面向 Windows x64，提供旧 PCB／LIB／NET 资料查看、测量，以及已载入自由走线的有限编辑和另存。当前为待验收候选，尚未创建版本标签，也未发布新下载包。原 v0.11.0-alpha 标签与附件保持不变。

## 本次功能范围

- 查看已支持的 PCB FILE 4 板图，缩放、平移、图层显隐、选择和属性检查。
- 元件检索与定位、两点测量及可选端点捕捉。
- 只读浏览 LIB；载入 NET 并映射网络／引脚；受限铜层分析。
- 对已载入的自由走线进行整数 mil 整线移动、删除、撤销和重做。
- 将修改另存为尚不存在的新 PCB，保留原件和已有目标，成功后更新保存点。
- 纳入主窗后台载入代际与重入保护、另存状态修复、严格写出几何校验。

正式新增走线入口仍禁用。内部显式参数的预览、编码、插入和另存核心随代码保留，其自动测试不表示用户可从空白开始画板。Ctrl+S 覆盖保存、元件放置／替换、完整 DRC、交互布线和生产输出均未开放。文字和部分轮廓为近似显示，铜分析不能用于生产放行；当前新输出的原 AUTOTRAX 完整兼容性仍未核定。

## 主要操作

| 操作 | 入口 |
| --- | --- |
| 打开 PCB | Ctrl+O |
| 浏览 LIB | Ctrl+L |
| 载入 NET | Ctrl+Shift+N |
| 元件检索 | Ctrl+F |
| 两点测量／端点捕捉 | Ctrl+M／Ctrl+Shift+M |
| 移动已有自由走线 | 选中后使用移动菜单，输入整数 mil 位移 |
| 删除／撤销／重做 | Delete／Ctrl+Z／Ctrl+Y |
| 另存新文件 | Ctrl+Shift+S，目标必须不存在 |

鼠标菜单与键盘入口共用命令模型；旧式字母菜单只在画布有焦点时生效。使用副本评估编辑效果；写出器拒绝覆盖原件和已有目标。

## 验证与发布条件

- 构建与自动测试：本候选独立 Release 构建通过，24/24组 CTest 全部通过，测试耗时42.15秒；Qt 测试使用 offscreen 平台，不操作桌面。CLI版本输出为`pt-renew 0.12.0-alpha`，退出码0。
- 新包真实窗口：用户已明确授权全面验收，按[48项清单](v0.12.0-alpha-gui-plan.md)安排单一Pi操作者覆盖声明功能及负向场景，当前尚无实际通过结论。仅运行本项目候选及合成资料，不启动原软件或访问用户板库。协调已完成119文件部署、ZIP与Qt DLL原字节核验，现场结果仍待。
- 干净 Windows 10／11：未验证；本机测试不能替代干净系统兼容性。
- 合并与标签：候选准备在独立 release 分支，尚未合入 main、创建或推送 v0.12.0-alpha 标签。仓库 AGENTS.md 规定 main 由用户执行合并；代理先完成可审候选和检查。

新标签应绑定最终通过审核的 main 提交，发行采用 Pre-release。若分发 Windows 包，须另核部署 DLL／许可／对应 Qt 源码及附件摘要，并修订这里的实际验证结果，不用历史包验收代替。

本机证据位于`.local-analysis/release-v0.12.0-alpha/`：build-result.json、build.log、ctest.log保存实际构建／测试／版本结果。后台脚本首次因PowerShell 5读取无BOM中文脚本发生解析错误，未执行编译；补UTF-8 BOM后完成上述验证，首次runner-stderr.log保持。构建使用本树`build/release-alpha12/`，不与其它工作树共写；未下载安装依赖，也未改旧发布包。
