# PT Renew v0.12.0-alpha：轻量编辑测试版（待合并发布）

本候选的 **48 项本机合成 GUI 场景已完成并经协调验收**，独立 Release 构建及24/24组CTest通过。当前尚未合入main、创建新tag或上传新版发行附件；已有v0.11.0-alpha标签与只读下载包保持不变。

完整结果见[48项真实窗口验收报告](v0.12.0-alpha-verification.md#gui-matrix)，范围及历史方案见[冻结清单](v0.12.0-alpha-gui-plan.md)。

## 本次功能

- 查看已支持的PCB FILE 4，缩放、平移、图层显隐、选择和属性检查。
- 元件检索与定位、两点测量及可选几何端点捕捉。
- 只读浏览LIB；载入NET及内置NETDEF来源切换、网络与引脚映射；受限铜层分析。
- 已载入自由走线的整数mil整线移动、删除、撤销和重做。
- 另存为尚不存在的新PCB，保留原件和已有目标，成功后更新保存点并保留历史。
- 主窗后台载入代际／重入保护，另存状态和严格写出几何校验。
- 非法LIB／NET载入失败时保留当前库预览或网表来源、筛选、选择及映射；成功验证后才替换。
- 后台载入时保留加载提示，不再被通用命令消息立即覆盖。

正式新增走线仍禁用。内部显式预览、编码、插入和另存核心保留，但不代表用户可从空白开始画板。Ctrl+S覆盖保存、元件放置／替换、完整DRC、交互布线和生产输出尚未开放。文字及部分轮廓近似显示，铜分析不能用于生产放行。

## 主要操作

| 操作 | 入口 |
| --- | --- |
| 打开PCB | Ctrl+O |
| 浏览LIB | Ctrl+L；Ctrl+Shift+L选择库文件 |
| 载入NET | Ctrl+Shift+N |
| 元件检索 | Ctrl+F，或画布J→C |
| 两点测量／端点捕捉 | Ctrl+M／Ctrl+Shift+M |
| 移动自由走线 | 选中后使用移动菜单，输入整数mil位移 |
| 删除／撤销／重做 | Delete／Ctrl+Z／Ctrl+Y |
| 另存新PCB | Ctrl+Shift+S，目标必须不存在 |

鼠标菜单与键盘入口共用命令模型；旧式字母菜单仅在画布有焦点时生效。原生文件框或检索文本输入不会触发画布菜单。

## 适用范围与保留记录

这48项是本机、合成资料、既定操作的有界验收，不代表所有格式、任意并发或生产能力通过。G46只支持观察到加载状态后实际关闭并换空板、约5秒无旧结果回填，不证明后台读取指令边界或无限期稳定。144DPI小窗存在说明裁切和tab省略，恢复尺寸与溢出菜单可操作；所有DPI未测。

干净Windows 10／11、安装器以及原AUTOTRAX完整输出往返仍未验证。正式新增图元、元件编辑、完整DRC、布线及生产输出继续未开放。

初版G22／G25真实失败、前两次G46受阻、原工具／网络失败均保留。A控制器及B早期观察器的原父wait缺口不能追补；A的overlap夹具早期修正及缺少修正后首次载入前独立摘要，也明确列在[历史记录](v0.12.0-alpha-verification.md#failures-and-followup)。当前C使用独立正确基线和完整退出链，不改写旧结论。
