# PCB FILE 4 只读解析与显示

日期：2026-10-21。开发分支：`feat/pcb-readonly-view`。

## 实现范围

本阶段在首阶段菜单骨架上加入真实几何模型和只读预览：

- 自由与元件内的走线、焊盘、过孔、圆弧、矩形填充、文字。
- 元件标号、封装名、注释和可见标签。
- 13 层的独立显隐、自动适配视口、滚轮缩放与中键平移。
- 文件读取和解析在后台线程中执行；主界面不等待大文件解析。载入期间可以关闭当前载入，迟到结果不会恢复已关闭板图；解析任务本身仍会在有界输入内完成。
- 仍无编辑、保存、LIB/NET 导入、DRC、布线或生产输出；原文件只读。

`LegacyPcbInspector` 保留为独立的粗粒度文件信息工具，不再负责新版板图载入。`LegacyPcbReader` 负责结构化解析，`BoardDocument` 持有不依赖 Widgets 的几何，`BoardRenderer` 负责绘制，`BoardCanvas` 负责视口和输入。

## 已支持的记录布局

所有几何数值按十进制整数读取，单位 **mil**，`1 mil = 0.0254 mm`。文件坐标 Y 向上；只在绘制变换中反转 Y，不在数据模型中改写坐标。

| 记录 | 后续字段 | 额外行 |
| --- | --- | --- |
| `FT` / `CT` | x1 y1 x2 y2 线宽 层号；允许可选第七整数属性 | 无 |
| `FP` / `CP` | x y 宽 高 形状 孔径 平面标志 层号 | 焊盘名称 |
| `FV` / `CV` | x y 外径 孔径 | 无 |
| `FA` / `CA` | 中心x 中心y 半径 象限掩码 线宽 层号 | 无 |
| `FF` / `CF` | x1 y1 x2 y2 层号 | 无 |
| `FS` / `CS` | x y 字高 方向 笔画宽 层号 | 文字内容，可以为空 |
| `COMP` | 标号行、封装名行、注释行、注释位置行、标号位置行、元件参数行 | 之后为 C 前缀图元，至 `ENDCOMP` |

元件参数行为 `原点x 原点y 标号显隐 注释显隐 放置属性`，显隐值 1 显示、2 隐藏。文件中的元件内部几何和标签已经是绝对板坐标，不能再次平移或旋转。

圆弧掩码位 0..3 分别对应右上、左上、左下、右下象限；15 为整圆。文字方向 0..3 是 90° 步进，16..19 是镜像形式。

焊盘当前接受形状 1..4；1 为圆/长圆，2 为矩形，3 为八角，4 为圆角矩形。八角与圆角矩形的倒角轮廓仍为近似预览，未达到生产几何验证程度；5/6 靶标等其他形状拒绝载入。

### 第二个样例发现的扩展字段

`660A.PCB` 的部分 FT 行实际有 **7 个整数**，而 `PLACED.PCB` 的 FT/CT 是 6 个。第七字段目前原样保存在 `Track::extra`，不猜测其电气意义，信息面板明确提示。显示仅使用已核对的六个几何字段。

这不是任意忽略尾部字段：仅该记录允许 6/7 字段，其他字段数量严格检查，七字段的非数值或更多字段会拒绝。没有实现写回，不会在保存时丢失未知属性。

## 限制与失败策略

- 仅接受 `PCB FILE 4`，需要正确的 `ENDPCB`、`COMP/ENDCOMP` 与图元所属范围。
- 标签按位置读取，内容即使等于 `FT`、`ENDPCB` 等关键字也不会被误当成结构记录。
- 遇到未知记录（包括尚未支持的 `NETDEF`）、不支持的图元形状或非法字段时，**整体拒绝载入**，显示行号，不跳过后伪装完整板图。
- 输入上限 64 MiB，单行 64 KiB，结构记录上限 200000；坐标限制 ±1000000 mil、正尺寸至 1000000 mil。限制是本工具的保护策略，不是对原格式上限的推断。
- 检查整数溢出、图层范围、孔径大小、零宽填充和畸形嵌套。
- 文字采用系统等宽字体近似绘制；字体笔画宽和精确字形未恢复。非 ASCII 旧代码页未确认，显示替代字符并警告，不悄悄按 UTF-8 解释。
- 图层为只读显示语义，没有从几何画面推导电气连通性；平面连接标志不等于已实现热焊盘或铺铜算法。
- 图层颜色为新版显示方案，不宣称已恢复用户原始 DFT 调色板。
- 自动适配使用几何和保守文字包围盒；不是精确的生产板框尺寸计算。

## 样例实测

本机实际启动应用、加载并查看截图：

| 样例 | 元件 | 走线 | 焊盘 | 过孔 | 圆弧 | 填充 | 文字（含可见元件标签） |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `PLACED.PCB` | 36 | 211 | 422 | 0 | 15 | 0 | 77 |
| `660A.PCB` | 0 | 170 | 1 | 2 | 2 | 35 | 0 |

第一个样例的布局与前期 DOSBox 显示的同一文件整体对应；第二个样例已实际显示圆形板框、双面走线、矩形填充、焊盘与过孔。没有声称做过逐像素一致性、全部电气属性或生产输出对照。

自动化测试覆盖全部基本记录、元件绝对坐标、空字符串/关键字标签、扩展字段保留、严格错误、只读文件摘要、像素级图层/钻孔遮罩、圆弧象限、坐标反转、关闭后的迟到异步结果和未实现写入禁用。测试使用新编写的合成数据，不提交原板图或截图。

最终 Debug 与 Release 均通过 2 组测试：菜单回归 18 项、PCB 解析/绘图与交互 29 项，**各配置合计 47 项通过、0 失败、0 跳过**（包含测试组初始化与清理）。图层复选框的鼠标测试使用系统样式提供的指示器位置，避免高 DPI 下硬编码点击偏移。发布包已在清除 Qt SDK PATH 的环境下实际载入 `PLACED.PCB`，原目录 99 个文件摘要全部不变。

本轮 Windows-MCP 尝试聚焦目标窗口时被系统 `SetForegroundWindow` 拒绝，因此没有强制抢焦点或宣称新的桌面点击流程通过；真实板图截图通过目标窗口原生截图获得，图层和按键的 GUI 回归由 QtTest 完成。
