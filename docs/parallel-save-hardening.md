## 修改与实际行为

后台读取未完成时，同步探测或关闭意图已经作废旧任务，旧实现却继续维持 loading；迟到回调还能解锁后续有效读取。放弃更改确认框的嵌套事件循环也可能递归弹框，或让已过期读取覆盖当前修改。本轮统一作废载入状态，回调在修改任何状态前核对代次，确认返回后再核对代次、修订和文档。取消关闭仍保留工作副本与历史，并立即恢复打开、另存能力。详见[主窗修复](mainwindow-load-lifecycle.md)。
