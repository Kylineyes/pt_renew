# 新增自由走线与工具取消设计

本页是下一阶段的实现设计，尚未实现。当前 `place.track`／F3 仍为未实现入口，`LegacyPcbWriter` 继续拒绝新增图元。本设计不改变既有移动、删除、另存为或其验收边界；原软件兼容及独立产品原生文件框的结果分别记录在对应核验报告中。

## 最小产品范围

第一版只在已载入的 PCB 工作副本中新增一条直线段。用户通过“放置 → 自由走线”或画布 F3 进入，明确选择线宽和已验证的铜层，再取起点、终点，确认后产生一次可撤销的文档编辑。先支持顶层 1 与底层 6；其他层、新建空板、折线连续布线、自动避障、网络归属及生产输出不在第一版范围。

坐标采用整数 mil，端点继续限制在 ±1000000 mil，线宽必须为正整数且不超出当前解析器尺寸范围。零长度线段拒绝提交。显示网格只负责显示，不能隐含启用坐标捕捉；初版采用明确的整数坐标输入，画布取点必须显示取整后的实际坐标。端点捕捉可在后续单独增加，不能借用只读测量的浮点结果直接写出。

一条线只有确认后才进入 `BoardDocument`、历史和派生分析。预览由画布覆盖层绘制，不建立永久图元或独立控件。未确认预览不改变 dirty、保存点、工作修订、记录数或网表；取消不创建空历史项。

## 记录身份与历史

现有 `PrimitiveId{kind,index}` 只在同一不可变文档及其修订内有效，不能承担跨撤销、删除和新增的永久身份。现有载入走线的 `source.line` 是原标签行号；当前读取器并未给这些记录填充有效的 `source.byteOffset`，不能把默认 -1 当成已恢复的字节位置。

实现时为走线增加文档内的明确身份类型，区分“载入记录”和“本会话新建记录”：

- 载入身份依据冻结源文档中的原记录行，写出时与重新解析的原记录逐项核对；`source` 继续提供原行和元件归属。
- 新建身份由 `BoardEditSession` 分配单调递增且非零的序号，不伪造原文件行。撤销后重做沿用同一身份；截断重做分支后不复用已分配序号。重开新文件后按新的来源文档建立载入身份。
- 身份在一份工作文档内必须唯一。新建记录没有元件归属和原来源行，载入记录不能改成新建记录以绕过原字段保护。身份是编辑模型的内部一致性约束，不是电气正确性证明。

历史操作统一为位置、可选 before、可选 after：新增只有 after，删除只有 before，移动二者都有；二者均无则拒绝。既有数组下标仍可作为已验证历史操作的位置提示，提交与恢复时需核对身份，不能仅凭下标修改另一条线。新增图元放在工作走线列表末尾，保持原走线相对顺序。

保存点沿用当前位置语义：新增后 dirty；撤销到保存点 clean；另存成功只标记保存点，不重新绑定输入或清空历史。取消和写入失败不消耗身份对应的有效操作，不截断重做分支。工具确认前检查捕获的文档身份和修订，发生换图或其他编辑时取消预览，避免把旧板坐标提交到新板。

## 工具状态与取消

画布采用一个明确的活动工具状态，避免测量和放置同时处理鼠标。新增工具至少有“等待起点”“等待终点”两个子状态；参数在进入时确定，提交一段后返回选择工具，连续布线另作后续功能。

| 事件 | 行为 | 文档与历史 |
| --- | --- | --- |
| 等待起点时按 Esc 或执行取消工具 | 退出到选择工具 | 不变 |
| 已有起点时按 Esc 或执行取消工具 | 丢弃整段预览并退出 | 不变 |
| 参数框取消 | 返回原工具状态，未进入放置 | 不变 |
| 提交零长度、越界或非法参数 | 保留预览并显示具体错误，可修改或取消 | 不变 |
| 合法终点确认 | 生成一条自由走线，清除预览并退出 | 一次历史，工作修订递增 |
| 中键平移、滚轮缩放 | 保持已取起点，重画预览；不提交线段 | 不变 |
| 打开文件框、换图、关闭板图、进入测量或库窗口 | 取消尚未提交的放置预览 | 已提交修改仍按既有保护处理 |
| 放置期间 Undo／Redo | 先取消预览，再执行用户明确选择的历史操作 | 沿用历史规则 |

“取消工具”必须有菜单命令，并与画布 Esc 共用取消函数。需要专门检查现有 `selection.clear` 的 Esc QAction 与画布 `keyPressEvent` 的分发顺序，避免快捷键先清选择却留下放置预览。文件名、参数框和其他文本输入中的 Esc 按所在对话框处理，F3 与旧式 P→T 入口也不得全局抢占文本输入。

进入工具时捕获当前可见铜层；用户隐藏该层或切换文档时取消预览。若隐藏层的目标不明确，不允许悄悄在不可见层生成图元。提交后沿用 `publishWorkingDocument`：失效选择／测量／旧铜结论，重映射已载外部 NET，迟到回调仍受代次和文档身份约束。

## 原字节插入与写出规则

不能只删除当前 writer 的“新增”拒绝条件。必须先让读取器记录经过语法解析确认的顶层记录边界、合法插入位置及所需换行样式，随后对冻结原字节增加一个有明确位置的插入补丁。文字、焊盘名称或 NETDEF 数据中也可能出现 `ENDPCB` 等文本，不能使用字符串查找代替语法记录边界。

初版插入位置规则如下：

1. 无内嵌 NETDEF 时，插在解析器确认的顶层 ENDPCB 标签行起始偏移之前，处于所有原图元之后。不得进入 COMP 范围或 DOS EOF 之后。
2. NETDEF 全部位于原图元之后时，可选择插在第一条尾部 NETDEF 标签之前，但须先验证原软件接受这一布局；原 NETDEF 及其字段逐字保留。
3. 当前读取器接受 NETDEF 与几何交错的输入。新增写出初版对此布局明确拒绝，不能假设 NETDEF 一定在文件尾；既有受限移动／删除另存能力继续按原规则处理。

新增 FT 的六字段或七字段布局、缺省第七字段以及换行约定，必须依据原 AUTOTRAX 新建／保存的隔离单线样例确认。现有“能读取六字段”和“原样保留七字段”均不足以决定新记录的默认编码；不得直接复制某条已有走线的未知附加属性。该事实未核定前，新增写出规则不能标为可用。

所有新增记录按会话创建顺序写入一个连续区域，删除后不留下空标签，撤销重做保持可预期顺序。原记录仍只允许既有整线移动或删除；元件内图元、宽度／图层／附加字段、其他图元和内嵌网表仍不允许借新增功能修改。空白、混合换行、非 ASCII 字节、原 ENDPCB 行、尾部空白及 DOS EOF 都继续原样保留。新增区域采用已确认的换行样式，不归一化全文件。

写出前重新解析原件并验证原字节摘要、来源身份和全部结构；将载入记录与新建记录分别校验后合成输出，再重新解析输出。比较时不能要求新建记录仍具有内存中的新建身份，而应验证其几何、字段和确定的记录顺序，同时验证所有未修改对象与 NETDEF 语义一致。原件摘要／字节数／记录数仍描述原输入；界面另外显示当前图元数。发布目标仍必须是全新文件，沿用同目录临时写入及不覆盖的原子改名。

## 实现与验证顺序

先以原软件隔离单线保存样例核定新 FT 编码及插入布局，再实现身份与新增历史；核心通过后增加工具状态、统一取消命令和界面入口，最后开放新增写出。不得仅显示可操作入口而留一个用户无法保存又未标明限制的编辑能力。

需要覆盖的验证是行为边界，而不是逐函数复写实现：新增→移动→删除→逐步撤销重做；截断分支后的身份唯一与保存点；预览取消不改变修订或文件；混合换行／无末尾换行／关键字标签／COMP／尾部或交错 NETDEF／DOS EOF 的准确插入与拒绝；伪造来源、重复身份、原图元字段变化仍拒绝；保存失败和文件框期间换图不丢文档。

GUI 验证应操作独立产品的菜单与 F3，实际提交一段、取消下一段、撤销重做、使用 Windows 原生文件框另存并重开。最后在原 AUTOTRAX 打开该新文件，核对新段、未改对象、工作文件名和计数；Qt 自重开不能代替这一步。所有现场继续使用指定 Pi 模型、隔离副本及原始证据，不沿用旧失败任务或扩大其次数／时限。
