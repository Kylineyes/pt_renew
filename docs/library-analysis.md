# PCB 4 LIBRARY 二进制分析与只读浏览

阶段：第五阶段，版本 0.5.0。开发分支：`feat/legacy-library-browser`。

## 1. 结论和范围

已对本地四个 LIB 文件进行只读结构分析，建立严格的二进制读取器和独立预览窗口。当前支持这些样例中实际观测到的布局，**不是对所有 Protel 库版本、全部语义或生产兼容性的承诺**。

| 文件 | 有效指针条目 | 结构检查通过并可预览 | 图元数量 | 未分配槽 | 未分配但残留名称的槽 |
| --- | ---: | ---: | ---: | ---: | ---: |
| TRAXSTD.LIB | 182 | 182 | 5064 | 18 | 1 |
| HW.LIB | 68 | 68 | 903 | 132 | 7 |
| LI.LIB | 53 | 53 | 1904 | 147 | 0 |
| VT8538.LIB | 15 | 15 | 155 | 185 | 0 |
| 合计 | 318 | 318 | 8026 | 482 | 8 |

上述是 C++ 读取器对目录、范围、声明图元数、字符串续记录及字段范围的检查结果，不等于已与原程序逐像素或逐项电气行为对照。

## 2. 文件与目录布局

- 文件按 **16 字节记录**组织；当前支持的文件头为 `00 00 0D` 加 ASCII `PCB 4 LIBRARY`，共 16 字节。
- 后续是 **200 个目录槽，每槽 32 字节**，占据字节 `0x10..0x190F`。
- 数据区从记录 **401** 开始，字节偏移为 `401 × 16 = 6416 = 0x1910`。
- 目录里的位置是记录号，不是字节偏移；转换必须乘 16。

每槽以 `16 + 槽号 × 32` 定位，内部偏移：

| 偏移 | 内容 |
| --- | --- |
| 0..1 | 当前样例均为零的保留字段 |
| 2 | 名称长度，最多 15 字节 |
| 3..17 | Pascal 短字符串内容和余留空间 |
| 18..19 | 小端 16 位声明图元数 |
| 20..21 | 小端 16 位起始记录号 |
| 22..31 | 当前样例均为零的保留字段 |

起始记录 `FFFF` 的槽不用于预览：有些仍保留名称和旧图元数，不能仅凭名称判断可用。其是否属于删除、未分配或历史编辑状态，尚未完全恢复，界面统一称为“未分配”，不把它当成有效封装。

HW/LI 的目录顺序与数据物理顺序不同。读取器根据记录号排序确定每条目的上界，**不按列表顺序推算下一项偏移**。重复数据指针和未支持的别名布局会明确拒绝；未知目录标志会将对应条目标记为不可预览。

声明图元数不包括字符串续记录。例如 TRAXSTD 的 AXIAL0.4 声明 8 个图元，包含 2 个焊盘名称续记录，实际占 10 个物理记录：从 412（`0x19C0`）读到 422（不含）。

## 3. 图元记录布局

每个图元记录的第 0 字节为层/类别信息，第 1 字节为类型；多字节数值使用小端格式。当前按有符号 16 位解读坐标，单位 mil，保留负坐标。

| 类型 | 当前解读 | 主要字段（字节偏移） |
| --- | --- | --- |
| 1 | 圆弧 | x/y：2/4；半径 u16：6；象限掩码 u8：8；线宽 u8：9 |
| 2 | 矩形填充 | x1/y1/x2/y2：2/4/6/8 |
| 3 | 焊盘 | x/y：2/4；宽/高/孔径 u16：6/8/10；形状/平面标志 u8：12/13 |
| 4 | 焊盘名称续记录 | 首字节零；长度：2，内容：3，最多 13 字节 |
| 5 | 线段 | x1/y1/x2/y2：2/4/6/8；线宽 u16：10 |
| 6 | 文字 | x/y：2/4；字高 u16：6；笔画宽 u8：8；方向/镜像编码 u8：9 |
| 7 | 文字内容续记录 | 首字节零；长度：2，内容：3，最多 13 字节 |
| 8 | 过孔 | x/y：2/4；外径/孔径 u8：6/7；附加标志：8；观测样例首字节零、附加标志 1 |

类型 4/7 必须跟随对应的 3/6，不能作为独立图元接受。图层、尺寸、孔径、形状、方向与圆弧掩码均验证范围；已知布局之外的非零保留字段停止该条目预览。

类型 2 不是过孔：样例中出现负坐标及两个相对角点，必须与类型 8 区分。圆弧线宽和文字笔画宽/方向是独立字节，不能将它们误读成一个 16 位尺寸。

这些字段解读来自本地字节、记录一致性与样例结构分析。类型 8 的附加标志、平面连接等电气意义没有恢复；保留完整原始快照并明确提示，不声称已实现热焊盘、网络或铺铜语义。

## 4. 失败策略和资源限制

- 文件最少 6416 字节、必须为 16 字节的倍数，本工具上限为 **8 MiB**。
- 单条目最多 **20000 图元**，目录累计最多 **200000 图元**；这是本工具的保护限制，不是对原格式最大值的推断。
- 文件头错误、目录指针越界、重复指针等导致整个库读取失败。
- 单条目遇到未知类型、缺失续记录、字符串超长、异常字段或越过下一条目的起始位置时，该条目**不返回任何部分预览**；其他完整条目仍可浏览。
- 目录界面会显示不可预览状态和原因，不跳过坏图元后伪装成完整封装。
- 输入保持原始快照，库 SHA-256 指向**整个文件**，不是单个封装的独立摘要。未引用的数据区和历史残留不会被当成有效条目，也没有被改写或删除。
- 非 ASCII 代码页尚未确认，相关字节显示替代字符并警告。字体、八角和圆角焊盘继续使用前阶段的近似显示。

## 5. 窗口与键盘入口

主窗口：

- **Ctrl+L**、“封装库 → 封装库只读浏览”或旧式 **L→B** 打开同一个独立窗口。
- **Ctrl+Shift+L** 或 **L→F** 选择 LIB 文件。
- 也可以使用命令行：

```powershell
& .\dist\pt-renew.exe --library 'D:\库\示例.LIB'
```

LIB 窗口内：

- 按名称作不区分大小写的字面子串筛选，选择条目后显示完整预览或明确错误。
- **Ctrl+F** 聚焦库筛选，不触发主板图的元件检索；**Ctrl+O** 选择 LIB。
- 支持滚轮缩放、中键平移、缩放/适配按钮和只读图元选择。
- 图元属性显示原始**字节偏移**，不把二进制记录号伪装成 PCB 文本行号。
- 预览画布内有选择时 Esc 先清除选择；无选择时按标准对话框方式关闭浏览窗口。
- “关闭当前库”会清空目录与预览；后台读取期间可放弃结果，迟到结果不会恢复已关闭的库。

库预览与主板图使用不同文档和画布。不会替换主板图、添加元件或启用保存。原库的封装默认值也不保证等于用户在 PCB 中修改过的元件实例；例如库 AXIAL0.4 的默认焊盘与样例 PCB 的 R7 焊盘尺寸并不完全相同，不能据名称相同就覆盖实例。

## 6. 实现与诊断工具

- `domain/FootprintLibrary.h`：不可变快照、目录、条目状态与预览数据。
- `io/LegacyLibraryReader.*`：纯 Qt Core 只读读取、边界验证及字段解码。
- `ui/LibraryBrowser.*`：独立窗口、筛选、后台加载、状态与图形预览；复用既有只读渲染/命中逻辑。
- `PrimitiveSource::byteOffset` 与 `BoardDocument::sourceContext`：区分二进制来源和文本来源，避免伪造“已放置元件”语义。
- `tools/InspectLibrary.cpp`：本地只读诊断工具，输出 JSON 摘要，不导出原封装图元。

```powershell
& .\scripts\Enter-QtEnv.ps1
cmake --build --preset release
& .\build\release\pt-library-check.exe 'D:\库\示例.LIB'
```

可传多个路径。退出码：0 为所有目录条目均通过当前预览检查；1 为文件或目录级失败；2 为目录可读取但存在不可预览条目。它不需要 GUI 窗口，但需要 Qt Core 运行库（开发环境脚本已提供路径）。
