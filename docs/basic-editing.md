# 基础编辑最小交付（0.11.0 候选）

本阶段实现自由走线的内存移动、删除、撤销与重做。原始 PCB 始终只读，保存和另存为均未实现；关闭或换图时只提供“放弃更改 / 取消”，没有保存按钮。源码和自动验证已完成，Release 部署候选已准备，**尚未进行真实 Windows 桌面 GUI 验收，不作为最终发布通过结论**。

基线为 `0d924c2`，实现分支为 `Kylineyes/feat-basic-editing`。实际 Pi 会话为 `01a173e4-f9b0-7743-838a-dfdcf7f3d2df`，已核对环境变量及会话的 `model_change` / `thinking_level_change`：`deng/gpt-6.1-sol`、`high`。未启动子代理，未操作宿主桌面或截图，未修改根 README、HANDOFF、PROGRESS，未合并或推送 dev/main。

## 实际支持范围

- 在主画布选择一个可见的 `Track`，且 `source.component < 0`，可从“移动 → 移动所选自由走线”输入整数 mil 的 ΔX/ΔY，或从“删除 → 删除所选自由走线”及画布 Delete 删除。
- 位移各轴限制为 ±2000000 mil，移动后的每个端点坐标必须仍在 ±1000000 mil 内。小数、非有限值、整数溢出和越界输入会拒绝；取消和零位移不修改文档、不增加历史。
- “编辑 → 撤销 / 重做”和画布 Ctrl+Z / Ctrl+Y 使用同一会话历史。删除撤销恢复原列表顺序、几何、宽度、图层、来源及未解释的 `extra` 字段。撤销回初始点恢复未修改状态；撤销后进行新编辑会清除重做分支。
- 元件内部走线、焊盘、其他图元、隐藏层及无文档状态不允许编辑。LIB 仍是独立只读预览；库窗口活动时主板编辑入口禁用，库预览快捷键不会改变主板工作副本。
- Delete、Ctrl+Z / Ctrl+Y 仅在主画布焦点内匹配；文本框和移动对话框保留自己的输入、删除、撤销行为。旧式画布字母菜单继续使用共享 `CommandCatalog`。
- 标题、状态栏与信息面板标识工作副本是否已修改，并持续说明不支持保存。属性面板保持只读；移动通过独立数值对话框完成。

尚未支持新增走线、拖拽、元件移动、网格约束、布线、PCB 写出、完整 DRC 或生产输出。PCB 接受范围、文字近似形状、铜层覆盖语义保持原范围。

## 文档、历史和失效处理

`src/application/BoardEditSession.*` 保存原始 `shared_ptr<const BoardDocument>` 与当前不可变工作文档。每条历史只有走线位置、修改前走线和可选修改后走线；不会把整板文档放进撤销栈。更新通过 Qt 容器写时复制创建当前文档：修改走线列表需要与走线数成正比的复制成本，其他列表继续共享。200000 条走线测试检查旧工作文档在后续操作后可释放，历史不会长期持有整板快照；这不等于已完成最大板图的现场交互性能验收。

每次实际编辑、撤销或重做均生成新文档身份并递增修订。应用层向画布、元件浏览器、网表浏览器分发同一份新文档；旧 `PrimitiveId` 不跨修订使用，会话接口拒绝旧修订身份。

画布清空选择、重叠候选、元件聚焦、测量锚点与结果、捕捉预览和网络高亮，重建命中及捕捉索引；退出测量取点状态，保留端点捕捉开关。普通编辑保留视图变换和图层显隐，避免移动边缘走线引发视图跳动。用户显式“恢复默认视图”时会重新计算当前几何包围盒并适配。

外部已载入 NET 在编辑后保留，重新建立引脚映射。铜层结论和覆盖问题清单立即清空，需显式重新分析。后台铜层结果同时检查代次、板图指针和网表指针；编辑前的迟到结果不会重新出现。后台 NET 读取也按文档代次淘汰，编辑发生时明确提示“正在读取的 NET 结果已放弃，请重新打开 NET”；之前已载入的外部网表继续保留并映射。

`sha256`、`byteSize`、`recordCounts` 只描述原输入。信息面板单列“原输入（始终只读）”和“当前工作副本”统计；铜层报告列出原输入 SHA-256 与当前工作文档修订，避免把原文件摘要冒充编辑后的文件摘要。

## 关闭、换图和失败保护

直接 `inspectFile`、后台 `requestOpenFile`、菜单打开及 CLI 启动载入共用成功应用路径。读取成功前保留旧工作副本；失败不清历史，也不要求先放弃修改。读取期间仍能编辑，成功结果应用时根据当时的修改状态提示，取消完整保留工作副本与撤销/重做历史；成功换图才开始新会话。

关闭板图、窗口关闭事件和应用退出共用放弃确认；系统会话结束通过 Qt `commitDataRequest` 接入相同保护，无交互能力时请求取消会话结束。关闭请求会先撤销待载入结果，避免后台读取完成在关闭确认框内再次弹出换图确认。取消关闭会保留工作副本与历史，但该次待载入任务的结果不再应用。

自动测试覆盖标准窗口关闭事件，没有触发宿主 Windows 注销或关机；系统会话结束的实际操作仍需单独受控验收。

## 待独立执行的真实 GUI 验收步骤

以下是提供给协调者安排的验收步骤，本实现任务没有操作宿主桌面或截图。

1. 使用上述部署候选启动 `supported.pcb`，确认版本 0.11.0、原输入摘要与当前工作副本信息分开、保存/另存为均标记未实现并禁用。
2. 选择红色自由走线中段 `(250,300)`，菜单“移动 → 移动所选自由走线”，先输入 `1.5`、`nan`、`999999` 检查拒绝，再取消；确认无修改标记、走线位置及历史不变。再次打开，输入 `ΔX=100, ΔY=-50`：端点应为 `(200,50) → (500,450)`，标题显示已修改。
3. 在画布 Ctrl+Z / Ctrl+Y 及编辑菜单交替操作；撤销至初始点应恢复未修改。选择移动后的走线并 Delete，再撤销：顺序和属性应恢复。画布按 D 后按 T 也能调用同一删除命令。
4. 选择元件内部走线 `(50,0)` 或焊盘，移动/删除应禁用；隐藏顶层后不能编辑该层。缩放、平移、隐藏底层后编辑顶层，确认视图与显隐保持；把自由线移动 `ΔX=10000, ΔY=10000` 后显式“恢复默认视图”，应适配移动后的当前几何，再撤销。
5. 先完成一组带端点捕捉的测量，再选择并编辑自由走线；确认选择/重叠候选、测量结果与黄色预览清空，在移动后的端点重新测量可捕捉到当前几何。撤销、重做后重复检查。
6. 载入 `editing.net`，运行铜层分析应显示支持模型内已连接。删除连接两个焊盘的自由走线，旧结论应立即消失，外部 NET 仍在；重跑应显示支持模型内仍分离。撤销后旧结论再次清空，重跑恢复已连接。快速在后台分析后编辑，确认旧结果不回填。
7. 在元件/网表检索框及移动数值框内输入，测试 Delete、Ctrl+Z / Ctrl+Y：仅操作文本。打开 `editing.lib`，确认只读标题及预览提示，选择库走线后按上述快捷键不会修改库或主板。
8. 保持工作副本已修改，尝试打开 `invalid.pcb` 或不存在的文件，原工作副本和历史应保留。再打开 `empty.pcb`，点“取消”完整保留原件和历史；点“放弃更改”才切换到空板并清除历史。
9. 修改后分别测试 Ctrl+W、窗口关闭按钮和退出菜单：确认只有“放弃更改 / 取消”，默认和 Esc 为取消。取消后继续撤销/重做应可用；确认放弃后关闭。系统注销/关机回调如需验收，应另约受控环境，勿在当前共享桌面直接触发。
10. 验收完成后复核 `inputs/manifest.json` 中所有输入摘要，并记录候选 EXE 摘要、真实动作与截图证据；未覆盖项单列，不把 offscreen 通过写成真实桌面通过。
