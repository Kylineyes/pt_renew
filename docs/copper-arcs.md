# 铜层圆弧分析

阶段：第八阶段，版本 0.8.0。开发分支：`feat/copper-arc-analysis`。

## 范围

受限铜层几何分析现可处理 1–6 铜层的 `FA` / `CA` 圆弧，覆盖单象限、相邻象限、分离象限及整圆；菜单、按钮和 CLI 沿用同一分析服务。铜层文字、负片平面、未知焊盘外形和未解释的走线附加字段仍会使全板网络保持“无法确定”。这项扩展仍不是完整 DRC 或实际导通证明。

## 字段依据与模型假设

解析器已有圆心、半径、象限掩码、线宽和图层六个字段。既有格式研究与绘图测试使用 Y 向上的板坐标，位 0–3 对应右上、左上、左下、右下，掩码 15 表示整圆。来源及公开格式交叉核对入口见 [PCB 只读预览](pcb-readonly.md)。本阶段没有复制第三方解析器或绘图代码。

端帽采用圆头，和现有新版预览一致。这是受限模型的明确假设，尚未证明与原软件的生产输出或 DRC 边界规则完全一致。本轮为原软件建立了隔离副本和合成象限样例，但 DOSBox-X 的窗口截图未提供可判读的板图，因此**不将本轮原程序运行尝试计为象限或端帽验收**。当前验证依据为已有字段事实、独立几何推导、合成测试及新版实际交互。

## 内外包络

设中心线半径为 `r`，半线宽为 `h`。圆弧铜区按 `[max(0,r-h),r+h]` 的扇环加上端点圆头建模。圆周仍使用 64 个方向，每个象限 16 条边，角步长为 `δ=2π/64`。

- 明确铜包络：外边界使用半径 `r+h` 的内接多边形，内边界扣除半径 `max(0,r-h)/cos(δ/2)` 的外接多边形。
- 可能铜包络：外边界使用半径 `(r+h)/cos(δ/2)` 的外接多边形，内边界只扣除半径 `max(0,r-h)` 的内接多边形。
- 两个端点使用相同圆形内外包络；明确接触要求正面积交叠，相切或仅外包络相交保持“无法确定”。

扇环直接由外边界和反向内边界组成单个多边形，再合并端帽，避免先对带孔整圆做象限裁剪。开发验证曾发现后一种做法会在 Qt 布尔运算中产生圆心附近的多余区域；现有回归用例要求圆心空白不会被当作铜。

当 `(r+h)cos(δ/2) - max(0,r-h)/cos(δ/2) <= 0.0001 mil` 时，内包络不能保证连续，整个圆弧不纳入接触图，并报告覆盖不完整。不会把分裂的近似轮廓强行视为一个明确铜组。该门槛属于当前模型的保护条件，不是原格式尺寸限制。

每个启用象限各占一个分析对象。掩码 5、10 中的两段分离圆弧只有在实际铜轮廓交叠时才会合并；相邻象限也通过普通接触图建立连接。整圆最多占四个对象，并计入既有 4000 对象上限、250000 次比较和 10 秒软时间预算。

## 验证

新增合成测试覆盖：

- 15 种非空掩码与 4 个象限探针的 60 组组合，含平移坐标和不连续象限隔离。
- 圆头端点、圆心留空、内外边界相切、明显间隙及正面积重叠。
- 大线宽覆盖圆心、跨层隔离、丝印圆弧不参与铜分析。
- 圆弧接走线、经镀通过孔跨层、跨网络接触候选。
- 退化尺寸、非法掩码、细线大半径、平面层/多层编号、象限拆分后达到资源上限。
- CLI 从 PCB 文本读取圆弧后报告连接，存在铜文字时仍返回无法确定；后台按钮、快捷键、旧式 N→A 及过期结果丢弃也使用圆弧样例回归。

最终 Debug 与 Release 七组测试均 **228 项通过、0 失败、0 跳过**（包含各组初始化与清理），其中铜层测试为 99 项。

发布目录已更新至 0.8.0，并核对 EXE 的 SHA-256 与 Release 构建一致。在移除 Qt SDK PATH 的环境下启动发布程序，实际点击分析按钮并检查窗口截图：两焊盘由上半圆相连的合成样例显示 1 个网络在支持模型内已连接、4 个分析对象、3 次候选比较，无跨网候选。4 个对象包括两个焊盘及两个相邻象限。

真实样例 `PLACED.PCB + DEMO.NET` 重新运行 CLI，仍为 430 个分析对象、5211 次比较、88 个网络无法确定及 21 组跨网接触候选，退出码 3。该板圆弧位于非铜层，新增支持不会改变上述计数；铜层文字继续使覆盖不完整。

验证输入均为合成数据或隔离副本，原目录 99 个文件的 SHA-256 与既有基线逐一核对。截图、运行副本和诊断报告仅保留在 `.local-analysis/verification-08/`，不提交原软件或原板图。
