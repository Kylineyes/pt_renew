## 统一实验判据

每次实验必须先冻结候选类别（固定候选或独立实验候选）、EXE及部署集合摘要、输入摘要、驱动摘要、PID/创建时间/HWND、实际Pi模型与推理级别。新执行使用新的证据目录和尝试ID。若以后派发工作者，创建新Task/Dispatch；旧批准文件不能绑定新启动。

| 事件 | 必须记录的内容 | 不接受的替代物 |
| --- | --- | --- |
| T0：请求建立 | 请求ID、类型、旧修订、输入/NET摘要；NET还需目标原生文件框确已关闭 | 原生框中选中路径、Type成功回执 |
| T1：后台实际进入 | 同一请求的实际工作线程/读取或算法入口见证；受控门闩已就绪且尚未释放 | `m_loading`、`m_analyzing`、禁用按钮、oplock发生break |
| T2：编辑提交 | 目标主窗口画布中的真实删除；新修订、图元数、dirty与几何截图，确认工作文档已发布 | 单独键盘回执、仅标题变化、预排的删除请求 |
| T3：释放及后台完成 | 确认T2后才释放同一请求的门闩，记录释放、原始任务返回和GUI完成回调处理 | 辅助进程finally退出、解锁文件、单独看到打开按钮恢复 |
| T4：最终状态 | 当前修订/几何/NET来源保持，旧铜报告和诊断未恢复；对应丢弃分支见证；无其他编辑或换图混入 | “没看到旧结果”、无完成信号或空列表 |

要求同一会话单调时钟能证明`T1 < T2 < 释放 <= 后台返回 <= 回调处理 <= T4`，并保存墙钟用于关联截图。后台返回早于T2时，即使GUI回调较晚也只能记录“回调迟到”，不算本项要求的后台执行重叠。不同进程时钟必须标明来源和映射误差；不能直接比较未经校准的数值。截图请求/响应时间形成区间，无法确定先后时不判通过。

截图与事件共同构成证据。实验日志不能代替真实GUI编辑、属性和最终状态，截图也不能代替后台完成见证。新运行驱动至少核验无image即失败、任何动作失败立即停链、已执行动作不重发，以及争用完整180秒静默；驱动离线通过独立计数。

## 独立实验构建的具体设计

以下为设计，**本轮未实现、未构建、未执行**。后续实施必须在新的实验分支（例如`experiment/async-result-barrier`）从固定`b0e5ac7`建立隔离工作区；冻结新的源码提交、构建参数、部署集合和EXE摘要。报告明确称为实验候选，结果不得计作原固定候选通过，也不得合入稳定产品或替换dist。

不把延迟放在原生文件框或GUI线程。采用默认关闭且仅实验构建启用的单次门闩；门闩应在原工作函数已经进入后阻塞实际工作线程，GUI事件循环保持可用：

- NET：`LegacyNetlistReader::readFile`成功打开隔离副本后、执行`file.read`之前记录`net-read-entered`并等待门闩。此时真实Qt工作线程已经进入读取路径、原生框已返回。释放后沿原读取/解析路径得到有效结果，返回前记录结果摘要。
- 铜层：`analyzeCopper`内实际算法入口设置门闩，记录所持旧修订/网表摘要和工作线程身份。位置应在算法计时器启动之前，避免等待门闩消耗10000ms预算；释放后执行原算法并记录原结果返回。报告称“算法任务已进入但被受控暂停”，不称CPU一直在做几何计算。
- 完成回调：保留原代次/身份判断原样，在判断处仅记录捕获/当前身份和`accepted`或`discarded`；不能增加自动丢弃、改代次或用测试分支替代原条件。门闩不能由编辑代码直接释放，否则无法独立证明T2发生在释放之前。
- 门闩控制：使用仅属于本实验进程/请求的命名事件或等价专用句柄，不设全局通用控制通道；持有者退出或超时必须释放并记`aborted`。看门狗上限60秒，一次本地等待不超过45秒。超时后不得重发编辑，不能把自动释放当有效T3。

两类都采用小型合成板和不同指纹的NET：已有网表A加载成功，待加载网表B名称/摘要不同但格式有效，避免“加载了同样内容”掩盖错误替换；铜层使用旧修订可连通、删除关键自由Track后分离的板，正向对照才能区分报告新旧。所有来源只读，新副本留摘要。

每类最多两次独立运行：一次不编辑的正向对照、一次有门闩的删除实验。对照先确认任务能够完成且结果可接受；失败则不进入竞争实验。竞争实验确认门闩就绪→真实画布选中并Delete一次→读图确认新修订、几何/数量、dirty→释放一次→记录返回及原条件的丢弃→核对当前状态。NET应保留A且不得出现B；铜层旧修订报告和覆盖诊断应保持清空。Undo/Redo可在竞争时间线结束后补观察，不混入T1—T4。

任何归属/图像/输入内容失败立即停止该链；争用完整退让180秒，期间没有键鼠、截图、ControlStatus或原生桌面请求。门闩看门狗可以在本地释放后台以防遗留，但该次记`aborted`，不能在退让后补写成有效竞争。到期只读复查，仍争用再退让180秒。不能重连、换工具入口、抢焦点或修改第三方包恢复控制。两次预算耗尽或任一前置证据无法取得时结算阻塞，不追加机会。

执行结束按目标身份正常关闭本实验进程和本次客户端，持有进程句柄记录退出码；若正常关闭失败，如实记录并按已核实归属处理，不结束其他工程进程。生成输入/部署前后摘要、事件与截图索引、失败/超时原件。使用指定Pi `deng/gpt-6.1-sol high`执行所有截图与验收，核对实际会话JSONL；已有同任务会话持续使用，不以输入已接受代替工作完成。
