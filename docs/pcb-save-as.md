# 自由走线编辑与受限另存为

本轮从 `dev=ef86125` 建立 `feat/pcb-save-as`，接续已有基础编辑候选，打通“载入原件 → 移动或删除自由走线 → 另存为新 PCB → 重新打开”的工作闭环。不修改已发布的 alpha 包，不创建新 tag，也不合入独立异步实验的门闩或控制服务。

## 用户操作

- 在主画布选择可见自由走线，从移动菜单输入整数 mil 位移，或通过删除菜单／画布 Delete 删除。
- 画布 Ctrl+Z／Ctrl+Y 或编辑菜单撤销／重做；文本框保留自己的编辑行为，元件内部走线及其他图元继续只读。
- 使用“文件 → 另存为新 PCB（保留原件）”或 Ctrl+Shift+S，选择一个尚不存在的 `.pcb` 文件。
- 成功后信息面板显示目标路径、大小及实际写出内容的 SHA-256。工作副本与最近另存内容一致时不显示未保存提示；撤销离开保存点重新变为已修改，重做回保存点恢复干净。
- 原输入路径与摘要继续作为来源显示。另存为不会重新载入文件或清空历史；后续再另存须选择其他新文件名。Ctrl+S 覆盖保存仍未开放。
- 保存取消、路径错误、已有目标、临时文件发布失败，均保留当前文档、修改标志和撤销重做。关闭有未另存更改的文档时仍提供放弃／取消，默认取消，可取消后先另存为。

外部 NET 仍独立载入，不会被写入 PCB。原本存在的板内 NETDEF 则逐字保留。原件只读不等于“可以把它当作默认覆盖目标”；即使源路径已被其他程序删除，本程序仍拒绝另存到原路径。

## 写出方式与限制

`BoardDocument::sourceBytes`保留载入时的原始字节，并在文档副本间共享。`LegacyPcbWriter`先重新解析原字节并核对来源摘要和结构，再按 `Track::source.line`识别原记录，拒绝新增、重复、重排或伪造来源的走线。

仅接受已有自由走线的整体整数平移或删除。宽度、图层、第七附加字段、元件内部走线、焊盘、过孔、圆弧、填充、文字、元件与内嵌网表的修改全部拒绝。删除仅移除对应的FT标签行和数值行；移动仅替换数值行的四个坐标词，保留分隔符、换行和其他字段。其余字节原样复制，包括空白、混合换行、非ASCII原字节、隐藏元件标签、未解释附加信息和尾部DOS EOF；不会从近似显示模型重新生成它们。

输出在写盘前重新解析，逐项与当前工作几何及网表比较；只有一致才允许创建临时文件。坐标继续限制在±1000000 mil整数范围。原读取器未支持的记录依然在载入阶段拒绝，不能通过另存为静默丢弃。

文件在目标同目录的独立临时文件中完整写入并flush，再使用`QTemporaryFile::rename`发布；Qt 6.12该API只有原子改名路径，不采用普通QFile可能存在的复制回退，且拒绝覆盖已有目标。发布失败由临时文件析构清理。目标存在检查用于提前反馈，最终不覆盖保证来自不替换的改名操作；这不等于已验证断电恢复、网络文件系统或所有存储设备的持久性。

目标文件名拒绝冒号，避免NTFS备用数据流；常规Windows设备名也在创建临时文件前拒绝。原路径、已有普通文件或链接不作为写出目标。保存不重新读取或改写原输入，外部程序对原件的变更也不会混入当前已冻结的工作副本。

## 编辑与后台状态

沿用基础编辑候选的不可变工作文档、单走线历史、修订、选择／测量失效及外部NET重映射。编辑后立即清空旧铜层结论；后台NET／铜回调继续按原代次／身份规则拒绝旧结果。另存本身不改变工作几何、文档身份或修订，只设置历史保存点；新编辑截断重做分支时，位于被截断分支的保存点随之失效。

文件框运行嵌套事件循环，因此选择目标前后检查修订一致；若期间发生编辑，会拒绝写出旧修订，要求重新另存。后台PCB载入期间禁用另存入口，不以尚未确认的新路径写出旧文档。

## 验证边界

`tests/WritingTests.cpp`覆盖原字节往返、移动与删除后的精确内容、来源及范围伪造、未支持图元修改、保存点分支、原路径／已有目标／NTFS路径拒绝、保存取消、保存失败保留历史，以及真实Qt移动框／文件框／重开流程。300字符目标名用于确定性触发临时文件已写入后的发布失败，并检查临时文件已清理；文件框期间编辑用例核对修订变化不会写出。

产品Debug／Release的全部CTest均为 **12/12组通过**，每配置QtTest310项（含初始化/清理），其中WritingTests **40项**、EditingTests23项。最后完整CTest区间约Release4.70秒、Debug19.61秒，以本机原日志为准；两组Python格式研究测试是CTest独立组，不和历史控制工具全集混算。GUI核验使用Qt Windows平台及链接同一产品UI的独立`pt-writing-tests`驱动，操作真实MainWindow、移动框、Qt文件框和命令；五业务函数（含初始化/清理共7项）一次通过、原进程退出0，四图由指定Pi `deng/gpt-6.1-sol high`实际读取。详见[独立核验报告](pcb-save-as-verification.md)。该方式不等于直接操作发行EXE，也不证明Windows原生文件框、原AUTOTRAX重开或全部历史格式兼容。

原固定候选的完整NET／铜竞争、900000mil极端现场、系统会话结束及原字形运行时边界仍按原报告保留。此开发阶段不把自动测试或另存往返计作这些旧现场通过；完整DRC、元件编辑、新增图元、布线和生产输出仍未实现。
