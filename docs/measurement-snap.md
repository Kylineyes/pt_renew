# 两点测量的几何端点捕捉

第十阶段，版本 0.10.0，开发分支 `feat/measurement-endpoint-snap`。

两点测量增加可选的几何捕捉。靠近支持的可见图元时，画布显示黄色方框；点击后使用模型中的确切坐标，避免用屏幕像素近似点击已知端点。此功能仍为只读测量，不产生尺寸图元，不修改板图，也不代表 DRC 或制造尺寸验收。

## 操作

1. 用 Ctrl+O 打开 PCB，在画布内按 Ctrl+M，或从“信息 → 两点只读测量”进入取点模式。
2. 从“信息 → 测量时捕捉几何端点”开启捕捉；画布内 Ctrl+Shift+M 调用同一命令，菜单勾选状态同步。
3. 将鼠标靠近端点或中心，确认黄色方框后点击。第二次点击完成测量，面板分别显示两端坐标、来源、ΔX/ΔY、距离及角度。
4. 未命中捕捉范围时仍自由取点，结果来源明确标为“屏幕自由取点”。不能把“捕捉开关已开启”理解为每一点都已捕捉。
5. 改变捕捉开关不会改写已经取得的第一点或已完成结果，混合取点会分别保留两端来源。
6. Esc 退出取点并保留已完成结果；更换或关闭板图清空测量和捕捉设置。捕捉默认关闭。

快捷键限于画布焦点，检索框等文本输入不触发捕捉命令。黄色标记在退出测量、离开画布、缩放、平移、改变图层或切换设置时清除，不复用过期屏幕位置。

## 几何范围

| 图元 | 候选点 |
| --- | --- |
| 走线 | 两端中心线端点 |
| 焊盘 | 模型中心；孔洞内部也可捕捉中心 |
| 过孔 | 模型中心，使用多层 13 的显隐状态 |
| 圆弧 | 已启用象限的连续弧段两端；相邻象限连接处不算端点，完整圆没有端点 |
| 矩形填充 | 四个角点 |
| 文字及元件标签 | 不参与，当前字形和边界仍为近似值 |

只考虑当前可见图层。不捕捉隐藏层、网格、走线中点、轮廓边缘或推测的交点。铜层分析的内外包络不参与取点；捕捉使用当前解析模型，不宣称恢复了原软件所有历史格式语义。

半径为屏幕上的 10 个 Qt 逻辑像素，按当前缩放换算到板坐标；候选采用圆形距离筛选。多个候选等距时按建索引顺序稳定选择：走线、焊盘、过孔、圆弧、填充，各类内按文档顺序。此规则不表示电气优先级，也不按绘制的前后遮挡猜测归属。

## 实现

`geometry/EndpointSnapIndex.*` 预先收集并按 X 排序模型候选，查询时先缩小 X 区间，再比较可见层和二维距离；不为候选创建控件。密集的同 X 坐标仍可能扫描较多候选，尚未完成最大板图压力验收。

`BoardCanvas` 将鼠标位置换算为板坐标，取点时重新查询捕捉，不把悬停缓存当作最终命中。`Measurement` 保存两端模型图元标识或空来源，主窗口据此显示实际来源及源文件行。图元标识仅属于当前不可变文档，换文件清空，不跨文件复用。

## 验证

Debug、Release 配置和构建成功，两个配置均 **10/10 组 CTest 通过**。新增端点组 **14 项通过、0 失败、0 跳过**（含初始化和清理）；八组 QtTest 合计 246 项。另两组为既有 Python 覆盖模块和文字工具测试。

新增测试覆盖最近点与圆形半径、等距稳定顺序、隐藏层、空索引及非法数值、焊盘/过孔中心、填充角点、文字排除、六种圆弧象限组合、12000 个候选模型的替换查询、精确 300/400/500 测量、混合来源、缩放后的屏幕半径、悬停清理、菜单与快捷键共享状态、文本输入保护、关闭文件清理及输入字节不变。

真实 GUI 验收使用自建 PCB（不是原软件板图），走线从 (100,100) 到 (400,500) mil，保留在 `.local-analysis/verification-39/measurement.PCB`。通过部署目录启动 0.10.0，子进程 PATH 排除 Qt SDK 和 Visual Studio，已核对部署 EXE 与 Release 构建 SHA-256 一致。

实际点击信息菜单进入测量并开启捕捉，靠近两个端点时出现黄色方框；稍偏离端点的点击仍得到 (100,100)、(400,500)，距离 **500.00 mil / 12.7000 mm**、角度 53.13°，两端来源均为模型几何捕捉、源文件行 2。隐藏顶层后以相同位置取点，来源变为屏幕自由取点，得到约 499.93 mil；重新显示图层后再次取点恢复 500.00 mil。输入文件摘要未变。

桌面工具初次发送组合键未稳定改变状态，不能将工具返回当作实际触发证明；现场以坐标菜单和截图确认功能，快捷键入口由 Qt GUI 事件测试独立验证。完整动作返回和截图留在忽略目录，未提交截图或构建产物。部署仍仅在本开发机验证，未完成干净 Windows 系统验收。
